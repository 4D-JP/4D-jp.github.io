* ACI0106566 HTTPレスポンスに`Location`ヘッダーが含まれる場合，ステータスコードが強制的に`302`に設定されました。結果的に`201 Created`レスポンスを返すことができません。` 4D.OutgoingMessage`（HTTPリクエストハンドラー）と`WEB SET HTTP HEADER`の両方で問題が再現します。RFC 9110 15.3.2によれば，`201`レスポンスには`Location`ヘッダーが定義されています。

* ACI0106558 Mac版のみ。`EXECUTE ON CLIENT`を続けて実行した場合，`3`回目以降は`2`回目と同じパラメーターがメソッドに渡されました。旧式ネットワークレイヤーの廃止に伴うリグレッションです。

* ACI0106506 Windows版のみ。マルチディスプレイの配置を変更した場合，プロパティリストがスクリーンの表示領域外にとどまることがありました。

* ACI0106545 「レコードの強制更新」モードで圧縮した場合，「レコードと一緒」に保存したオブジェクト値が失われました。「データファイルの中」（レコード外のBLOBブロックに保存）であれば問題ありません。

* ACI0106495 スリープ解除時にアプリケーションがフリーズすることがありました。リクエスト送信中にクライアントがスリープモードに移行すると問題が再現します。

* ACI0106564 [データ収集](https://developer.4d.com/docs/ja/Admin/data-collect/)の`isShadowCopyActivated`が常に`True`でした。

* ACI0106565 バイナリモードのプロジェクトを終了した場合，アプリケーションがフリーズしました。

* ACI0106542 プロジェクトを指定せずにアプリケーションを起動した場合，ライセンスの自動アップデートが実行されず，ライセンス番号の入力を求められました。

* ACI0106546 `PackProject`キーを`False`設定してアプリケーションをビルドした場合，初回起動時に純正コンポーネントのインストールを促す依存関係マネージャーのダイアログが表示されました。
